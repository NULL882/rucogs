## Обзор
Модули для tgstation бота discord

- based : тестовый модуль cog для изучения использования обработчиков событий
- fridge : холодильник для хранения продуктов и последующего их извлечения
- pet : случайные разные команды
- tgcommon : общие модели, используемые набором cogs tg*, действительно должны быть реорганизованы в его собственное репозиторий в какой-то момент
- tgdb : команды для взаимодействия с базой данных tg
- tgverify : модуль верификации, который применяет две роли к пользователю, если он привязывает свой игровой ключ ckey к своей учетной записи discord 
- timeout : cog, который позволяет вам предоставлять ролям возможность тайм-аута пользователей, при этом можно устанавливать максимальные периоды тайм-аута
